Oke dikesempatan kali ini tagar post #retrospective saya ubah menjadi judul "Ulasan Pekan ini" karena simple judulnya, klo ada kata retrospective keknya terlalu keren ahaha 🤣, tapi isinya sama kok, kalem aja!

Oke kita mulai ulasan hal-hal menarik pekan ini:

## Perkakas

ada sumber alat bantu kerja yang baru nih, di [https://file-examples.com/](https://file-examples.com/) kita bisa unduh file sampling berupa video, audio, document, gambar ataupun file jenis lainya untuk kebutuhan testing, khususnya upload file, jadi bisa nyari file yg ukurannya, resolusinya ataupun ekstensi nya sesuai dengan skenario test yang kita mau.

## Bacaan

Rekomendasi bacaan pekan ini:

- Bahasan penulisan automation test code yang baik ga perlu sesuai prinsip clean code banget. **Good production code is well-factored; good test code is *obvious*.** [https://mtlynch.io/good-developers-bad-tests/](https://mtlynch.io/good-developers-bad-tests/)
- Pandangan mengenai value testing yang baik pada tim [https://www.techwell.com/techwell-insights/2018/11/cost-software-testing](https://www.techwell.com/techwell-insights/2018/11/cost-software-testing)
- Perihal penulisan pytest code yg baik [https://raphael.codes/blog/customizing-your-pytest-test-suite-part-1/](https://raphael.codes/blog/customizing-your-pytest-test-suite-part-1/) dan [https://raphael.codes/blog/customizing-your-pytest-test-suite-part-2/](https://raphael.codes/blog/customizing-your-pytest-test-suite-part-2/)
