# fachrul.id

Personal blog of Fachrul Choliluddin, served by GitHub Pages from the root of
`master` (custom domain in `CNAME`). The HTML at the repo root is generated by a
small Python script from markdown in `content/`. Publii is no longer used.

```
content/posts/<slug>.md   one file per article, URL is /<slug>/
content/tags.toml         tag names and descriptions, URL is /celoteh/<tag>/
content/site.toml         site title, nav, social links, analytics id, page sizes
templates/                Jinja2 templates and the CSS (inlined into every page)
tools/build.py            the generator
tools/check_urls.py       proves no public URL, canonical or feed item was lost
media/posts/...           images
```

## Setup (once)

```sh
python3 -m pip install -r requirements.txt   # Markdown, Jinja2, Pygments; Python 3.11+
```

## Write a new article

1. Create `content/posts/<slug>.md`. The file name becomes the URL, so pick it
   once and never rename it.

   ~~~markdown
   +++
   title = "Judul Artikel"
   date = 2026-10-07T20:00:00+04:00
   tags = ["tutorials", "automation-python"]
   description = "Satu-dua kalimat untuk Google dan preview link."
   cover = "/media/posts/<slug>/cover.jpg"
   cover_alt = "Deskripsi gambar"
   +++

   Isi artikel dalam **markdown** biasa.

   ```python
   print("code block otomatis di-highlight")
   ```
   ~~~

   Only `title` and `date` are required. Optional keys: `updated`,
   `description` (defaults to the first 50 words), `cover`, `cover_alt`,
   `cover_caption`, `og_image` (link-preview image, defaults to the cover),
   `seo_title` (the browser-tab title), `canonical` (only for articles first
   published elsewhere), `listed = false` (reachable by URL but hidden from the
   home page, tags and feeds).
2. Put images in `media/posts/<slug>/` and link them as
   `![alt](/media/posts/<slug>/foto.jpg)`. Raw HTML also works anywhere in the
   markdown (embeds, figures with captions, tables).
3. A new tag needs no setup; add it to `content/tags.toml` to give it a display
   name or description.

## Build, check, preview

```sh
python3 tools/build.py        # writes the HTML into the repo root
python3 tools/check_urls.py   # must end with "OK"
python3 -m http.server 8788   # open http://localhost:8788/
```

Commit the generated HTML together with the markdown and push to `master`;
GitHub Pages publishes it. Deleting or renaming a post does not remove its old
folder: delete that by hand only if you really mean to drop the URL.

## Notes

- `_config.yml` keeps `content/`, `templates/` and `tools/` out of the
  published site. Do not add `.nojekyll`: GitHub Pages' Jekyll step is what
  hides dot-folders and `__pycache__` (for example under `sdet/`).
- The page sizes in `site.toml` are part of existing URLs (`/page/7/`,
  `/celoteh/tutorials/page/4/`). Do not raise them.
- `tools/extract.py`, `tools/snapshot.py` and `tools/verify_content.py` were
  used once to migrate from Publii; they need `beautifulsoup4` and `lxml`.
